2 — End-to-end tradeable inventory process

This is intentionally split into four stages so the path can be read left-to-right: capture, resolve, enrich, and act.

flowchart LR
    start([User wants to\ntrade an item]) --> choose{How will\nyou provide items?}

    subgraph INPUT[1. CAPTURE INVENTORY]
        direction TB
        type[Type or paste\nitem names]
        screenshot[Upload inventory\nscreenshot]
        normalize[Normalize names\nand quantities]
        preprocess[Preprocess image]
        ocr[OCR reads\nitem text]
        review[Review, remove,\nor correct matches]
        type --> normalize
        screenshot --> preprocess --> ocr --> review --> normalize
    end
    choose -->|names| type
    choose -->|screenshot| screenshot

    subgraph CATALOG[2. RESOLVE ITEMS]
        direction TB
        match[Match each item\nto catalogue]
        kind{What kind\nof item?}
        relic[Void relic]
        prime[Prime part or\nblueprint]
        mod[Mod, riven, arcane,\nor other tradeable]
        unknown[Not found or\nneeds correction]
        match --> kind
        kind -->|relic| relic
        kind -->|prime item| prime
        kind -->|mod / other| mod
        kind -->|no match| unknown
    end
    normalize --> match
    unknown --> correct[Choose suggestion\nor fix spelling] --> match

    subgraph ENRICH[3. ENRICH DATA]
        direction TB
        status[Read owned status\nand quantity]
        price[Fetch market data:\nprice, volume, platform]
        drops[For relics:\nfetch drop table]
        status --> price
        status --> drops
    end
    relic --> status
    prime --> status
    mod --> status

    subgraph ACTION[4. TAKE ACTION]
        direction TB
        inventory[Show tradeable\npersonal inventory]
        select[Select item +\nquantity to sell]
        confirm[Review price,\nquantity, and listing]
        listing[Create listing\nwith approval]
        inventory --> select --> confirm --> listing
    end
    price --> inventory
    drops --> inventory
    listing --> end([Listing created])
